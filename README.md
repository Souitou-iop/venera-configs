# Venera / VeneraX 漫画源配置库 (Enhanced)

本项目是 [venera-app/venera-configs](https://github.com/venera-app/venera-configs) 的社区维护与增强分支，主要针对原版漫画源中存在的**接口失效、内存污染崩溃、风控拦截超时、旧版客户端指纹**等问题进行持续修复与体验优化，适配 Venera 及衍生客户端（如 VeneraX）。

---

## 🚀 订阅源地址

在 Venera / VeneraX 应用内进入：**设置 → 漫画源管理 → 添加漫画源库（右上角）**，填入以下任意订阅链接：

- **jsDelivr CDN（国内直连加速，推荐）**：
  ```text
  https://cdn.jsdelivr.net/gh/Souitou-iop/venera-configs@main/index.json
  ```
- **GitHub Raw 订阅地址**：
  ```text
  https://raw.githubusercontent.com/Souitou-iop/venera-configs/main/index.json
  ```

## 🛠️ 近期重点修复日志 (Changelog)

### 拷贝漫画 (`copy_manga.js`) - v1.5.0
针对原版 1.4.1 源在日常阅读中暴露的多个严重痛点进行了全面重构与风控加固：
1. **根治“看完一话后切换下一话必报 Network error 崩溃”的内存污染 Bug**：彻底切断 `refreshAppApi` 将混淆域名（`t66y.com`）覆盖配置导致 Dart 层抛出 `NoSuchMethodError` 的崩溃问题，固定主 API 节点并增加底层配置解析防护。
2. **解决 HTTP 210 限频死锁与 30 秒超时冲突**：将原版 40 秒长等待优化为 1.5~3 秒微抖动退避重试（单次最高不超过 4 秒），彻底消除因长等待被阅读器 30 秒超时强制报错的情况。
3. **客户端请求特征升级为 3.0.9**：全面升级至官方最新正式版 `3.0.9` 请求头特征，规避服务端对旧版的标记拦截。
4. **动态设备指纹自愈**：遇到风控拦截苗头自动在内存中重新生成全新随机合规设备标识，重置黑名单权重。
5. **多镜像节点自动故障转移**：内置 3 组官方主力 API 节点集群（`api.copy2000.online`、`api.copy-manga.com`、`api.mangacopy.com`），遇到单一节点限频或网络波动时自动无感切换。
6. **优化海外线路直连（`region: 0`）**：精准剥离非必要的大陆广告请求参数。

### Komiic (`komiic.js`) - v1.1.0
1. **适配官方新版 imageTickets 鉴权**：Komiic 官方后端近期升级废弃了旧版图片直链（原接口返回 `HTTP 402 Payment Required` 导致正文图片无法加载），现已全面适配 `imageTicketsByChapterId` 签名鉴权与 `X-Image-Ticket` 请求头注入，正文图片加载已恢复正常。

## 📱 适配测试与问题反馈

### 已测试环境
本项目目前**仅经过本人在以下设备与网络环境中的实际测试与验证**：
- **测试设备**：
  - **Mac** (macOS 26.6)
  - **Windows**
  - **iPhone** (iOS 27)
  - **安卓手机** (Android 16 / HyperOS 3)
  - **安卓平板** (Android 16 / HyperOS 3)
- **网络环境**：
  - 测试基于**具备海外访问能力的代理网络环境 (Proxy / Global Gateway Environment)** 进行，部分海外站点（如 Komiic 等）在直连网络下可能受到区域限制。

### 问题反馈指南
其他设备或网络环境下如果出现问题，欢迎提交 Issue 反映。提 Issue 时**请务必说明清楚**：
1. **使用的具体设备型号与系统版本**（如：具体品牌、操作系统版本、Venera/VeneraX 客户端版本）；
2. **网络环境类型**（如：直连网络、系统代理或路由网关代理）；
3. **遇到的具体问题特征与复现步骤**（如：无法获取章节、切章卡死、具体报错提示文案）；
4. **导出的日志文件**（客户端内：设置 → 导出日志）或具体报错截图。
