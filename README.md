# VeneraX 漫画源配置增强库 (venerax-configs-enhanced)

本项目是基于 [venera-app/venera-configs](https://github.com/venera-app/venera-configs) 构建的社区维护与增强分支，主要针对原版漫画源中存在的**接口失效、内存污染崩溃、风控拦截超时、旧版客户端指纹**等问题进行持续修复与深度优化。

> [!IMPORTANT]
> **关于客户端兼容性与测试说明**：
> 本项目中的漫画源配置遵循 Venera 标准 JS 规范编写，理论上兼容原版 Venera 及各类衍生客户端。但由于原版 Venera 已正式归档停更，**本项目的所有核心修复、防封策略、鉴权适配与性能优化均仅在 [VeneraX](https://github.com/Kyosee/VeneraX) 客户端上进行过真机深度实测与验证**。强烈建议搭配 VeneraX 客户端使用以获得最佳稳定性和无缝阅读体验。

## 🧭 各漫画源最佳线路与网络推荐指南 (Recommended Lines)

经在**中国大陆直连网络（国内骨干网节点）**与**海外代理网络**环境下的全面实测，各漫画源的最佳线路选择与推荐设置如下：

| 漫画源 | 支持的线路/分流选项 | 国内直连环境推荐 | 代理/科学上网环境推荐 | 实测与设置建议 |
| :--- | :--- | :---: | :---: | :--- |
| **拷贝漫画** | • 大陆线路 (`Region 1`)<br>• 海外线路 (`Region 0`) | **海外线路 (`Region 0`)** | **海外线路 (`Region 0`)** | • **强烈推荐全局保持「海外线路」**：直连省去 3.3 秒广告握手，代理下 300ms 秒开；<br>• 大陆线路强制请求国内广告 ID 且易触发服务端 210 风控拦截。 |
| **Komiic** | • 主站 (`komiic.com`)<br>• 大陆线路 (`komiic.cc`) | **中国大陆线路 (`komiic.cc`)** | **主站 (`komiic.com`)** | • 国内直连时主站会被拦截，请在源设置中选择「中国大陆线路 (`komiic.cc`)」；<br>• 开启代理时选择主站速度最佳。 |
| **包子漫画** | 5 个官方镜像主域名 | **`twmanga.com`** / 默认 | **默认域名** | • 默认域名在国内若偶发遇到 DNS 污染或 302，可在源设置中将主域名切换为 `twmanga.com`。 |
| **禁漫天堂** | 官方 5 条分流线路 | **分流4 (`cdngwc.club`)** / 自动 | **任意分流** / 自动 | • 脚本已内置 5 条官方线路自动故障转移，直连遇阻断时会自动无感轮换至可用分流。 |
| **漫画人 / 爱看漫** | 官方国内直连 | **默认直连** (无需设置) | **直连 / 规则分流** | • 原生国内站点，全国 CDN 直连秒开，建议代理软件中将其设为直连分流。 |
| **哔咔 / EH / nhentai** | 官方境外节点 | ❌ 无法直连 | **必须开启代理** | • 境外专属服务，国内直连被阻断，需在代理环境下使用。 |

## 🛠️ 近期重点修复日志 (Changelog)

### E-Hentai (`ehentai.js`) - v1.2.3 & nhentai (`nhentai.js`) - v1.1.3
1. **E-Hentai (v1.2.3)**：修复非标准 DOM（如部分模板省略 `tbody`）导致的画廊空列表与解析崩溃；重构 `taglist` 正则匹配与 `options[0]` 空指针安全防护；全链路统一注入防封浏览器 UA 与 Referer。
2. **nhentai (v1.1.3)**：适配官方 v2 API 新版嵌套 JSON 数据结构（兼容 `title.pretty` / `cover.path`）；显式注入 `comic.chapters` 单本画廊章节结构，解决阅读器切章异常；增加 60 秒搜索缓存防止 429 限频拦截。

### 官方生肉与台漫源批量加固 (`shonen_jump_plus.js` v1.1.3 / `comic_walker.js` v1.1.0 / `ccc.js` v1.0.3)
1. **少年Jump+ (v1.1.3)**：引入 Apple iTunes API 动态同步 App 最新版本特征；将系列详情与章节列表优化为 `Promise.all` 并发拉取，翻页加载速度大幅提升。
2. **カドコミ (v1.1.0)**：升级至官方 1.6.0+ 请求特征；完善版本探活异常捕获；补充 `onTagSuggestionSelected` 根级占位避免框架回调报错。
3. **CCC追漫台 (v1.0.3)**：修复分类与搜索 `options` 为空时的异常崩溃；搜索关键词增加 `encodeURIComponent` 编码防护。

### 拷贝漫画 (`copy_manga.js`) - v1.5.0
针对原版 1.4.1 源在日常阅读中暴露的多个严重痛点进行了全面重构与风控加固：
1. **根治“看完一话后切换下一话必报 Network error 崩溃”的内存污染 Bug**：彻底切断 `refreshAppApi` 将混淆域名（`t66y.com`）覆盖配置导致 Dart 层抛出 `NoSuchMethodError` 的崩溃问题，固定主 API 节点并增加底层配置解析防护。
2. **解决 HTTP 210 限频死锁与 30 秒超时冲突**：将原版 40 秒长等待优化为 1.5~3 秒微抖动退避重试（单次最高不超过 4 秒），彻底消除因长等待被阅读器 30 秒超时强制报错的情况。
3. **客户端请求特征升级为 3.0.9**：全面升级至官方最新正式版 `3.0.9` 请求头特征，规避服务端对旧版的标记拦截。
4. **动态设备指纹自愈**：遇到风控拦截苗头自动在内存中重新生成全新随机合规设备标识，重置黑名单权重。
5. **多镜像节点自动故障转移**：内置 3 组官方主力 API 节点集群（`api.copy2000.online`、`api.copy-manga.com`、`api.mangacopy.com`），遇到单一节点限频或网络波动时自动无感切换。
6. **优化海外线路直连（`region: 0`）**：精准剥离非必要的大陆广告请求参数。

### Komiic (`komiic.js`) - v1.1.0
1. **适配官方新版 imageTickets 鉴权**：Komiic 官方后端近期升级废弃了旧版图片直链（原接口返回 `HTTP 402 Payment Required` 导致正文图片无法加载），现已全面适配 `imageTicketsByChapterId` 签名鉴权与 `X-Image-Ticket` 请求头注入，正文图片加载已恢复正常。

### 紳士漫畫 (`wnacg.js`) - v1.0.11
1. **重大解析修复**：修复由于 UA 导致请求进入移动端布局、进而造成 DOM 选择器失效崩溃的问题。
2. **功能增强**：支持从标题首对 `[xxx]` 中精准提取作者与社团名，并新增 4 种搜索排序选项（最新、最早、最多评论、最多收藏）。

### 漫画柜 (`manhuagui.js`) - v1.2.3
1. **算法升级**：逆向官方最新的 LZString + splic 混淆算法，解决新上线长篇漫画章节解密失败问题。

### 包子漫画 (`baozi.js` v1.1.7) & 爱看漫 (`ikmmh.js` v1.0.6)
1. **包子漫画**：修复章节正文图片解析选择器，新增 `s1.bzcdn.net` 与 `s2.bzcdn.net` 节点。
2. **爱看漫**：详情与章节并发拉取加速，新增探索页 5 分钟轻量缓存。

### 禁漫天堂 (`jm.js` v1.4.2) & Hitomi.la (`hitomi.js` v1.2.2)
1. **禁漫天堂**：支持官方 5 条分流线路自动故障转移、域名 12h 本地缓存加速与图片打乱算法边界对齐。
2. **Hitomi.la**：集成 galleryblock/nozomi LRU 缓存与 B-tree 搜索去重加速，大幅减少冗余网络请求。

## 🤖 自动化运维与质量保障 (Automation & Monitoring)

本项目配置了完整的 CI/CD 自动化检测与加速分发机制，保障漫画源的高可用性：
1. **自动化定时健康巡检（GitHub Actions）**：
   - 每周自动对库内所有精选源的连通性、响应延迟与状态码进行探活检测，第一时间捕获源站改版与失效。
2. **全网社区源更新追踪机器人**：
   - 自动监控全网 7+ 个主流社区 Fork 仓库，发现新源或更高版本时自动在仓库提 Issue 通知维护者。
3. **即时 CDN 缓存刷新（jsDelivr Purge）**：
   - 每次向 `main` 分支推送更新时，自动触发全球 CDN 节点缓存清理，确保客户端在检查更新时秒级拉取最新脚本。
